Licences vary and matter if you intend to take the advice in Chapter 38 about what to borrow. Most of the list is Apache-2.0 or MIT, ggml and llama.cpp are MIT, and some vendor kernel libraries carry additional terms. Check before you vendor anything. The ABI structures reproduced in Chapter 5 and Appendix A mirror kfd_ioctl.h , which is GPL-2.0 with the Linux syscall note, and that note is what makes it fine to describe the interface in a book and to call it from code under any licence.

Where to look for what

For how a scheduler really works, read vLLM’s vllm/v1/core/sched/ and SGLang’s scheduler, starting with the admission and preemption paths. For how paged attention kernels are written, read FlashInfer

and vLLM’s attention backends, or AITER on AMD. For how structured output is made cheap, read XGrammar’s mask cache. For how quantised GEMM is made fast, read Marlin and CUTLASS’s mixedinput examples. For how GPU-driven collectives are structured, read MSCCL++’s primitives. And for how a model’s config becomes execution, read any engine’s model definition file for a model you already know, because the shortest path to understanding an architecture is its 200-line serving implementation.
