Appendix E: Glossary

AQL — Architected Queuing Language, AMD’s public GPU command packet format.

Arithmetic intensity — FLOPs performed per byte moved from memory, which determines roofline position.

Attention sink — early tokens that absorb excess attention because softmax must sum to one and causal masking makes them universally visible.

Barrier bit — bit 8 of an AQL packet header, delaying the packet until all preceding packets complete.

BF16 — 16-bit float with 8 exponent and 7 mantissa bits, FP32’s range at reduced precision, and the usual training and checkpoint format.

Block table — per-sequence map from logical KV block index to physical block index.

Chunked prefill — processing a prompt in bounded pieces across iterations so decode isn’t stalled.

Continuous batching — allowing requests to join and leave a batch at every decode step.

CU / SM — compute unit on AMD, streaming multiprocessor on NVIDIA, the scheduling and execution unit holding many wavefronts or warps.

DCA — dual chunk attention, remapping positions so no relative distance exceeds the trained range.

Decode — the phase generating one token at a time, memory-bandwidth-bound.

Disaggregation — running prefill and decode on separate pools of hardware.

Doorbell — a memory-mapped register the host writes to tell the command processor new packets are ready.

E4M3 / E5M2 — 8-bit float formats with 4 or 5 exponent bits and 3 or 2 mantissa bits.

E8M0 — exponent-only 8-bit scale format used by MXFP4, where the value is 2^(x−127).

EP — expert parallelism, placing whole MoE experts on different devices.

FlashAttention — tiled attention using online softmax, never materialising the score matrix.

FlashDecoding — decode attention parallelised across the KV cache with a merge of partial softmax results.

Goodput — throughput counting only requests that met their SLOs.

GQA — grouped-query attention, fewer KV heads than query heads.

Infinity Cache — AMD’s chip-wide memory-attached last-level cache, 256 MB on MI355X, distinct from the per-XCD L2.

ITL / TPOT — inter-token latency, or time per output token.

KFD — the AMD kernel compute driver interface at /dev/kfd .

Kernarg — the buffer holding a kernel’s arguments, pointed at by the dispatch packet.

LDS — Local Data Share, AMD’s per-CU software-managed scratchpad, 160 KB on CDNA4.

MFMA — AMD’s matrix fused multiply-add instruction family.

MLA — multi-head latent attention, KV compressed into a low-rank latent plus a decoupled RoPE component.

MoE — mixture of experts, many parallel FFNs with a router selecting a few per token.

MXFP4 / NVFP4 — 4-bit float formats with block scales, E8M0 per 32 elements and E4M3 per 16 elements plus an FP32 tensor scale respectively.

Occupancy — resident wavefronts or warps as a fraction of the hardware maximum.

PagedAttention — managing the KV cache as fixed-size blocks with a per-sequence block table.

Prefill — the phase processing the prompt, compute-bound.

Prefix caching — reusing computed KV for shared prompt prefixes.

RadixAttention — SGLang’s radix-tree prefix cache.

Roofline — the model bounding achievable throughput by compute ceiling and bandwidth times arithmetic intensity.

RoPE — rotary position embedding.

Speculative decoding — drafting several tokens and verifying them in one target forward pass, with rejection sampling preserving the distribution.

TP / PP / SP / CP — tensor, pipeline, sequence, and context parallelism.

TTFT — time to first token.

Wavefront / warp — the SIMD execution group, 64 lanes on AMD CDNA and 32 on NVIDIA.

XCD — accelerator complex die, one of the 8 compute chiplets on MI355X, each with 32 CUs and 4 MB of L2.

xGMI — AMD’s inter-GPU Infinity Fabric link.

YaRN — a RoPE extension method combining frequency-dependent interpolation with an attention temperature adjustment.
